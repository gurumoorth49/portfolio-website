Guess the number

🎯 Guess the Number — Python Game Guess the Number is a simple command-line game developed using Python. In this game, the computer randomly generates a number between 1 and 100, and the player has a limited number of attempts to guess the correct number. The program provides useful hints after every valid guess. If the entered number is lower than the generated number, it displays “Too Low”, and if it is higher, it displays “Too High”. The game also validates the user's input and handles invalid values using "try-except". The game ends when the player guesses the correct number or uses all available attempts. If the player cannot guess the number within the limit, the program displays the correct number. Key Features: - Random number generation using Python's "random" module - Number range from 1 to 100 - Limited attempts - Too High / Too Low hints - Invalid input handling - Win and loss conditions Technologies: Python, Random Module, Loops, Conditional Statements, Exception Handling

Rock Peper Scissors

✊📄✂️ Rock Paper Scissors — Python Game Rock Paper Scissors is an interactive command-line game developed using Python. The player competes against the computer by selecting one of three choices: Rock, Paper, or Scissors. The computer generates its choice randomly using Python's "random" module. The program compares the player's choice with the computer's choice and determines whether the player wins, the computer wins, or the round is a draw. The game keeps track of both the player's score and the computer's score throughout the match. It allows up to 10 attempts and displays the final result after the game ends. Invalid choices are also handled to prevent incorrect input from affecting the game. Key Features: - Player vs Computer gameplay - Random computer selection - Rock, Paper, and Scissors choices - Score tracking - Draw, win, and loss conditions - 10-attempt game limit - Invalid input handling - Final winner declaration Technologies: Python, Random Module, Loops, Conditional Statements, Exception Handling

Bank management system

🏦 Bank Management System — Python Bank Management System is a menu-driven Python project designed to simulate basic banking operations through the command line. The program stores account information using a Python dictionary and provides multiple options for managing a bank account. Users can create a new account by entering their name and a 4-digit password. The system automatically generates an account number and stores the account details, including the account holder's name, password, balance, and transaction history. After creating an account, users can log in using their account number and password. The system provides options to check the current balance, deposit money, withdraw money, and view transaction history. Deposit and withdrawal operations automatically update the account balance and record the transaction. The program also includes input validation using "try-except" to handle invalid account numbers, amounts, and menu choices. During withdrawal, the system checks whether the account has sufficient balance before completing the transaction. Key Features: - Create a new bank account - Automatic account number generation - 4-digit password validation - Account login system - Check account balance - Deposit money - Withdraw money - Insufficient balance checking - Transaction history - Invalid input handling - Menu-driven interface - Dictionary-based data storage Technologies: Python, Dictionaries, Loops, Conditional Statements, Random Module, Exception Handling
